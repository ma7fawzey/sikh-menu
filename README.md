# سيخ — SHAWERMA & CO Digital Menu

منيو ويب Mobile-first مع:
- شاشة دخول Logo Reveal
- Animations و smooth scrolling
- أقسام قابلة للفلترة
- Cards تفاعلية للأصناف
- نافذة تفاصيل للصنف
- تصميم Dark / Premium / Street Food
- جاهز للرفع على GitHub Pages

## التشغيل
افتح `index.html` مباشرة في المتصفح.

## GitHub Pages
1. اعمل Repository جديد.
2. ارفع الملفات كما هي.
3. من Settings → Pages اختر Deploy from branch.
4. اختر `main` و `/root`.
5. استخدم الرابط الناتج في QR Code.

## مهم
بعض أسماء الأصناف في صورة المنيو غير واضحة 100%، لذلك راجع النصوص والأسعار قبل الطباعة النهائية.
